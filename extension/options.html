01 · Connection

Nextcloud account

→

Use a revocable Nextcloud app password (Settings → Security → App passwords), especially with two-factor authentication. It is stored locally in Firefox.

02 · Import

Bring Firefox bookmarks over

⇢

Manual one-way import into Nextcloud. Nothing is changed or deleted in Firefox.

Allow Firefox bookmarks access to choose what to import.

Existing URLs are skipped. Firefox folders are flattened into the selected Nextcloud folder. This does not create Nextcloud folders.
